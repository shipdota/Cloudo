## 2024-05-20 - [Supabase Python Client & os.environ Overheads]
**Learning:** Using `os.environ.get()` inside request handlers (e.g., `submit_score`) causes measurable overhead; caching values as module-level constants improves retrieval speed by ~92%. Furthermore, `supabase.create_client()` spins up instances of `httpx.Client` for auth, postgrest, and storage, which manage HTTP connection pools. If these are instantiated per-request without being closed, it causes connection exhaustion and memory leaks. The standard python library does not automatically clean them up efficiently.
**Action:** Always cache static configuration constants at module load time. When creating new `supabase.create_client` instances within route handlers or threads (to prevent token clobbering across requests), ensure `user_client.auth._http_client.close()`, `user_client.postgrest.session.close()`, and `user_client.storage.session.close()` are called in a `finally` block to prevent `httpx` connection pool leaks.
