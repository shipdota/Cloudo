## 2024-05-18 - [In-Memory Cache Stampede Prevention]
**Learning:** [When implementing thread-safe caching with threading.Lock, it's critical to minimize the lock duration by only reading/writing the cache dictionary inside the lock block. In Python, expensive operations like render_template() should be executed outside the lock. Also, to prevent cache stampedes upon expiration, the double-checked locking pattern is needed: check if the cache is valid (fast path), and if not, acquire the lock and re-check the validity before performing the expensive update operation. Variables used for the check, such as the current timestamp, must be recalculated inside the lock to avoid using stale values.]
**Action:** [Always use double-checked locking and update the timestamp variable inside the lock block when building an in-memory TTL cache to prevent stampedes and race conditions.]
