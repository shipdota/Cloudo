## 2024-06-22 - Avoid Cache Stampedes in Python
**Learning:** When implementing in-memory TTL caches using `threading.Lock`, you must use the double-checked locking pattern. Specifically, recalculating the expiration timestamp inside the lock block is necessary. Otherwise, multiple threads waiting on the lock could evaluate the expiration using stale timestamp values, leading to consecutive cache rebuilds and stamping out the performance benefit.
**Action:** Always recalculate current state (e.g., `time.time()`) *inside* the lock and re-evaluate the TTL expiration condition before attempting the expensive update. Also, never return expensive operations (like `render_template`) directly from inside the `with lock:` block because Python delays lock release until *after* the `return` expression evaluation, which blocks other threads unnecessarily.
